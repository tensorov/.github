## What I do

Two tracks that meet in production:

- **AI agents** - MCP servers and tooling, agent-session tooling, and agent-verifiable outputs: runs that carry evidence, not just stdout.
- **Rust infrastructure** - fast CLIs, network services, and self-hosted systems that agents and teams rely on.

## Selected work

| Project | What it is |
| --- | --- |
| **[polyforge](https://github.com/tensorov/polyforge)** · Rust | Turns any GitHub repo into an agent-verifiable knowledge base over MCP, backed by a Merkle hash evidence ledger. Also ships as a [GitHub Action](https://github.com/tensorov/polyforge-action). |
| **[opencode-kanban](https://github.com/tensorov/opencode-kanban)** · Rust | Terminal kanban for driving OpenCode coding sessions - Git worktrees + tmux management, built on OpenCode's API (`npx @qrafty-ai/opencode-kanban`). |
| **[ssh-rtg](https://github.com/tensorov/ssh-rtg)** · Go | Reverse SSH tunnel gateway - remote port forwarding with Ansible roles and a standalone client script. |
| **[matrix-mcp-server](https://github.com/tensorov/matrix-mcp-server)** · TypeScript | MCP server that gives agents access to a Matrix homeserver: chat, rooms, automation. |
| **[homelab](https://github.com/tensorov/homelab)** · Ansible | Homelab datacenter as code: Traefik ingress, Authentik SSO, Docker Compose stacks - vaulted secrets, restic backups, CI-linted. |
